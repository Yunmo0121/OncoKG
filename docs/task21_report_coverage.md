# Task 21 · Report coverage across retrieval cutoffs

The reference is the report produced when the current prototype sees all
five claims for each of the eight synthetic development cases. For every
method and cutoff from one to five, the script counts the items retained
and records the exact omissions by case. It checks that each displayed item
also exists in its full-snapshot report.

An item is scoped to one case. Within a case, matched claims are identified
by Claim ID, missing checks by claim and check text, supplemental links by
claim and URL, and flags by drug, status and supporting IDs. Identical items
within a case are counted once. The denominator is the sum of available
items across cases. It includes mismatch, incomplete-context and no-safety-
assessment review statuses where the full snapshot displays them.

## Observed coverage at k=3

| Method | Context-matched claims | Missing checks | Review flags | Supplemental links |
| --- | ---: | ---: | ---: | ---: |
| BM25, MiniLM, and rank fusion (each) | 5/7 | 12/19 | 0/24 | 8/8 |
| KG paths, 2 hops | 6/7 | 17/19 | 8/24 | 6/8 |
| KG paths, 4 hops | 6/7 | 17/19 | 8/24 | 8/8 |
| KG paths + context, 2 hops | 7/7 | 16/19 | 10/24 | 6/8 |
| KG paths + context, 4 hops | 7/7 | 11/19 | 6/24 | 4/8 |

At k=5, both 2-hop methods still omit 12 flags and two supplemental links
because their candidate lists can exclude supporting claims. Both 4-hop
methods and all three text methods recover every reference item at k=5.
This distinguishes omissions caused by candidate selection from omissions
caused by the reporting cutoff.

The reference is generated by the same prototype rules and curated snapshot
as the ranked reports. These counts measure report coverage. Independent
review and medical validation are outside this experiment. An omitted flag
makes no statement about safety.

## Reproduce

From the repository root with the two local curated evidence inputs and
saved Task 15 rankings, choose a fresh output filename:

```bash
python codes/demo/task21_report_coverage.py \
  --rankings docs/results/task15-retrieval-comparison.json \
  --output docs/results/task21-report-coverage.json
```

The output records input fingerprints, the summary totals, and exact omitted
items for each case, method and cutoff. This step uses the standard library.
